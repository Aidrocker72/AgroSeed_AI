# AgroSeed AI - Система прогнозирования изменения цен сельхоз-семян

## Описание

AgroSeed AI - это система машинного обучения для прогнозирования изменения цен на сельскохозяйственные семена на основе исторических данных и новостных факторов. Система включает в себя несколько микросервисов, объединенных в единую экосистему.

## Архитектура

Система состоит из следующих компонентов:

1. **Backend API** - основной API-шлюз системы
2. **ETL Service** - сервис сбора и обработки данных
3. **AI Service** - сервис машинного обучения для прогнозирования
4. **Frontend** - пользовательский интерфейс

## Стек технологий

- **Backend**: FastAPI, SQLAlchemy, PostgreSQL
- **ETL**: Python, Pandas, Requests, APScheduler
- **AI**: Scikit-learn, Prophet, NumPy, Pandas
- **Frontend**: Nuxt 3, Vue 3, TypeScript, Chart.js
- **Контейнеризация**: Docker, Docker Compose
- **ORM**: SQLAlchemy (Python), Pinia (Vue)

## Особенности

- Микросервисная архитектура для масштабируемости
- Машинное обучение для точного прогнозирования
- Автоматический сбор данных из внешних источников
- Адаптивный пользовательский интерфейс
- JWT-аутентификация
- Поддержка мультиязычности
- Высокий уровень безопасности (OAuth2)
- Поддержка SLA 99.99%
