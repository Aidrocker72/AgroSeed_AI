# AgroSeed AI - AI Service

AI сервис для системы прогнозирования изменения цен сельхоз-семян.

## Описание

AI сервис отвечает за обучение моделей машинного обучения и выполнение прогнозов на основе исторических данных о ценах на семена и новостях.

## Архитектура

Сервис построен по многослойной архитектуре:
- **Routers** - точки входа API
- **Models** - ML модели для прогнозирования
- **Schemas** - Pydantic схемы для валидации данных

## Функциональность

- Обучение моделей на исторических данных
- Прогнозирование цен на семена на 7, 14 и 30 дней вперед
- Поддержка комбинированной модели (Random Forest + Prophet)
- Сохранение и загрузка обученных моделей

## Запуск

### Локальный запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите приложение:
```bash
uvicorn main:app --reload
```

### Запуск в Docker

```bash
docker build -t agroseed-ai-service .
docker run -p 8000:8000 agroseed-ai-service
```

## API Endpoints

- `POST /predict` - Прогнозирование цен на семена
- `POST /train` - Обучение модели на предоставленных данных
- `GET /health` - Проверка работоспособности сервиса
